PicoHALO

An ambient environmental display with animated eyes, sensor readouts, and LED ring — built on the Raspberry Pi Pico family.

GC9A01A Round Display AHT20 · BMP280 NeoPixel Ring × 16 Pico / Pico W / Pico 2 / Pico 2W Touch Sensor
01 — Overview

What is PicoHalo?

PicoHalo is an open-source ambient environmental display firmware for the Raspberry Pi Pico family. It combines a 240 mm round GC9A01A TFT display, an AHT20 humidity/temperature sensor, a BMP280 pressure/temperature sensor, and a 16-LED NeoPixel ring into one cohesive device.

The display animates a pair of blinking eyes, shows random messages, and displays live sensor data on touch. The LED ring shifts through rainbow colors under normal conditions and turns solid red or blue to warn you when temperature, humidity, or pressure fall outside safe ranges.

02 — Boards

Supported Boards

PicoHalo ships as four separate firmware files — one per board variant. Pick the file that matches your hardware exactly.

Pico
RP2040 · 264 KB SRAM
Original board. No wireless. All PicoHalo features fully supported.
Pico W
RP2040 · CYW43439
Wi-Fi & Bluetooth capable. Same PicoHalo features, wireless reserved for future use.
Wi-Fi Ready

RP2350 · 520 KB SRAM
Faster dual-core ARM/RISC-V. Improved rendering. No wireless.
Pico 2W
RP2350 · CYW43439
Most capable variant. Faster CPU + Wi-Fi/BT. Best choice for future expansions.
Wi-Fi Ready
ℹ All four board variants run identical PicoHalo features at v1.0. The firmware files differ only in the internal board target (chip variant, pin mapping). Do not flash a Pico 2 file onto a Pico — it will not boot.

04 — Setup

Flashing Firmware

There are two ways to flash PicoHalo: using the online Web Flasher (easiest, no software install), or manually using the Arduino IDE or Thonny.

Method A — Web Flasher (Recommended)

  1. Visit the PicoHalo Web Flasher at the link provided in the repository README.
  2. Select your board variant (Pico / Pico W / Pico 2 / Pico 2W) and your preferred temperature unit (°C or °F).
  3. Hold the BOOTSEL button on your Pico and plug it into your computer via USB while holding the button. Release once plugged in.
  4. Your Pico will appear as a USB drive called RPI-RP2 (or RP2350 for Pico 2). Click Flash in the web flasher.
  5. The flasher will upload the firmware. When it completes, the Pico reboots and PicoHalo starts automatically.

Method B — Manual (Arduino IDE)

  1. Install the Arduino IDE 2.x from arduino.cc.
  2. In Arduino IDE, go to File → Preferences and add the Pico board URL to "Additional boards manager URLs":
    https://github.com/earlephilhower/arduino-pico/releases/download/global/package_rp2040_index.json
  3. Go to Tools → Board → Boards Manager, search for Raspberry Pi Pico/RP2040 and install it.
  4. Install all required libraries via Sketch → Include Library → Manage Libraries (see Libraries section below).
  5. Open the .ino file for your board variant from the repository. Select your board under Tools → Board.
  6. Set USE_FAHRENHEIT to true in the source if you want °F. Connect your Pico and click Upload.

06 — Configuration

Choosing °C or °F

PicoHalo ships as two separate firmware variants per board: one Celsius, one Fahrenheit. If you use the Web Flasher, simply select your preference from the dropdown — no code changes needed.

If you compile manually, locate the following line near the top of the .ino file and change it:

// Set to true for Fahrenheit, false for Celsius
#define USE_FAHRENHEIT false

Temperature alerts always compare against Celsius safe ranges internally regardless of the display unit. The display correctly converts to °F when USE_FAHRENHEIT is true.

07 — Usage

Boot Screen

On power-up, PicoHalo displays a boot screen for approximately 5 seconds. During boot:

  • The display shows "Pico HALO v1" and a loading progress bar.
  • The LED ring cycles through rainbow colors while loading.
  • Sensors are initialized in the background.

After 5 seconds the eye display appears automatically and normal operation begins.

08 — Usage

Eye Display (Home Screen)

The default display shows two animated white eyes on a black background. PicoHalo's eye behaviors:

Blinking

Eyes blink automatically every 3–6 seconds (random interval). Each blink lasts 200 ms. Timing is randomized to feel natural.

Random Messages

Every 1–3 minutes, the display clears and shows a short motivational message centered on screen (cyan text). After 5 seconds the eyes return automatically.

Alert Overlay

If a sensor value leaves the safe range, a colored notification box appears at the bottom of the eye screen. It stays visible for up to 2 minutes. The LED ring also switches to solid red (too high) or solid blue (too low).

09 — Usage

Sensor Data Page

Tap the capacitive touch sensor (GP22) once to toggle between the eye display and the sensor data page. Tap again to return to the eye display.

The sensor page shows three labeled boxes with live readings:

ReadingSourceUpdate rate
TemperatureAHT20Every 5 s (display) / 3 s (internal)
HumidityAHT20Every 5 s (display) / 3 s (internal)
PressureBMP280Every 5 s (display) / 3 s (internal)
ℹ Sensor values are sampled every 3 seconds internally. The on-screen display refreshes every 5 seconds to reduce flicker. Range checks and LED alerts happen at the 3-second sample rate even when the sensor page is not visible.
10 — Alerts

Alerts & Notifications

PicoHalo monitors sensor values against configurable safe ranges. When a value goes out of range:

  • A notification box appears at the bottom of the eye screen (colored border + text).
  • The LED ring turns solid red for "too high" alerts.
  • The LED ring turns solid blue for "too low" alerts.
  • The alert clears automatically after 2 minutes if the value returns to range.

Only one alert is shown at a time. Priority order: Temperature → Humidity → Pressure.

11 — LED Ring

LED Ring Behavior

Rainbow (Normal)

All 16 LEDs cycle through a smooth rainbow hue rotation. The hue offset shifts by +2 per loop iteration, giving a slow, continuous spin effect.

Solid Red (Too High)

All 16 LEDs turn solid red when temperature, humidity, or pressure exceeds the maximum safe threshold.

Solid Blue (Too Low)

All 16 LEDs turn solid blue when temperature, humidity, or pressure falls below the minimum safe threshold.

Safe Ranges

These ranges are defined in the firmware source. Values outside these ranges trigger visual and LED alerts.

Modifying Ranges

Open the .ino source file and locate these definitions:

#define TEMP_MIN  18
#define TEMP_MAX  28
#define HUM_MIN   30
#define HUM_MAX   70
#define PRES_MIN  950
#define PRES_MAX  1050

Change values, recompile, and flash. If you use the Web Flasher, pre-built binaries use the default ranges above.

14 — Troubleshooting

Troubleshooting

Display stays black after flashing

Check TFT wiring. Verify GP18 → SCK, GP19 → MOSI, GP17 → DC, GP16 → RST, GP20 → CS. Ensure the display VCC is on 3.3 V, not 5 V.

Sensor shows 0.0 values or freezes

Verify GP4 → SDA and GP5 → SCL. Check that BMP280 SDO is pulled high for address 0x77. Both sensors must share the I²C bus correctly with pull-up resistors (4.7 kΩ to 3.3 V).

LEDs do not light up

NeoPixel rings require 5 V on VCC. The Pico's 3.3 V is insufficient for full brightness. Use the VBUS (5 V) pin. Add a 300–500 Ω resistor in series with the data line.

Touch sensor not responding

Ensure the sensor output is connected to GP22 and the sensor is powered (3.3 V / GND). Some capacitive modules have a sensitivity trim potentiometer — adjust it for reliable triggering.

Wrong board file flashed

The Pico will likely not boot, or will produce unexpected behavior. Enter BOOTSEL mode again (hold BOOTSEL, plug USB) and reflash the correct variant.

15 — FAQ

Frequently Asked Questions

Can I add more messages?

Yes. Open the source file and find the msgs[] array. Add your strings inside the array and update msgCount to match the new total count.

Can I change how often messages appear?

The message timer is randomized between 60 000 and 180 000 ms (1–3 minutes). Find msgDelay = random(60000, 180000); in setup() and loop() and adjust the values.

Will PicoHalo work on a Pico 2 with different pinouts?

Yes. The Pico 2 uses the same GP numbering. The firmware is identical except for the board target in Arduino IDE. Select "Raspberry Pi Pico 2" as your board.

The alert stays on too long. Can I change it?

The alert duration is 120 000 ms (2 minutes). Find millis() - notificationStart > 120000 in drawNotification() and change the value.

Is Fahrenheit support different firmware or a config flag?

In the source it's a single #define USE_FAHRENHEIT flag. The Web Flasher packages both as separate pre-compiled binaries so you just pick one — no code editing needed.

Can I use a different LED ring size?

Yes. Change #define NUM_LEDS 16 to match your ring. The rainbow animation scales automatically.
